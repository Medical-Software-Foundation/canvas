Screening Follow-up Cascade adds the longer questionnaire to the same note whenever a short screener comes back positive, so the follow-up no longer depends on someone remembering.

- Works out of the box for PHQ-2 (score 3 or more adds PHQ-9) and GAD-2 (score 3 or more adds GAD-7).
- Every rule is a setting: which screener, the comparison and threshold, the follow-up questionnaire, and a waiting period so the same follow-up is not added twice.
- Rules can chain to clinician-rated scales, such as adding MADRS after a PHQ-9, and can pick a different follow-up for clinicians who prefer one, such as HAM-D instead of MADRS.
- It adds nothing if the follow-up is already on the note or was done recently.
- For practices that built their own copies of a screener, it can also record the screener's score and flag it abnormal.
- If any scored question is unanswered, it does nothing rather than act on a partial score.

Good to know:

- Canvas scores its built-in PHQ-2 and GAD-2 itself. This plugin only scores copies a practice made.
- The follow-up questionnaire must already exist in the practice's Canvas.
- Clinician preferences are kept in the plugin's settings by an admin; clinicians can't change their own.
- The plugin is off until the practice turns it on.
